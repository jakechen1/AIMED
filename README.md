# AIMED - AI.MED Lab Repository

## Introduction to AIMED Lab
The AI.MED Lab focuses on research at the intersection of Artificial Intelligence and Medicine, developing tools and datasets to advance healthcare and biological discovery.

## Repository Overview
This repository hosts a collection of projects, tools, and datasets developed by the AI.MED Lab. It includes resources for bioinformatics analysis, web applications, and curated datasets primarily focused on biological research, with some specific emphasis on COVID-19 studies.
